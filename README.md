# 定格截图

这是一个用 Python 写的桌面小工具，可以：

- 按固定时间间隔自动截图
- 按分钟点自动截图，例如每 1 / 5 / 10 / 30 / 60 分钟截图
- 每天在多个指定时间点自动截图
- 选择截图保存目录
- 选择全屏截图或拖拽框选截图区域
- 截浏览器里的网页画面，只需要把浏览器放好后选中网页区域
- 使用更简洁的桌面界面来操作

## 运行环境

- Python 3.9 及以上
- macOS / Windows
- 界面依赖：`PySide6_Essentials`
- macOS 默认使用系统自带截图能力
- Windows 需要 `Pillow`

## 安装依赖

```bash
pip install -r requirements.txt
```

如果你是在这台 Mac 上首次运行，现在建议先执行一次依赖安装。

## 启动方式

```bash
python 定格截图.py
```

如果你是直接在访达里双击使用：

- 不要双击 `定格截图.py`，那会把它当成代码文件打开
- 请双击 `启动定格截图.command`
- 如果已经生成 `定格截图.app`，也可以直接双击它

## 使用说明

1. 打开软件后，先设置保存目录。
2. 如果你要截整个主屏，可以直接开始。
3. 截图区域可以选择“全屏截图”或“选取区域”。
4. 截图方式可以选择“间隔”“分钟点”或“指定时间”。
5. 如果选择“指定时间”，输入时间后点击“添加时间点”，也可以直接按回车添加。
6. 点击“开始截图”，需要停止时点“停止截图”。

## 注意事项

- 在 macOS 上，第一次截图时通常需要给 Python 或你当前使用的终端开启“屏幕录制”权限。
- 截图区域坐标是基于主屏幕的像素位置。
- 如果你有多显示器，建议先在主屏幕范围内使用。
